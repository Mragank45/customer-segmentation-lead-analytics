# Customer Segmentation & Lead Generation Analytics

A Python project that (1) groups customers into value-based segments using **RFM analysis + K-Means clustering** and (2) analyses **lead sources and conversion rates** to show where sales effort pays off.

Built as a portfolio version of the work I did during my internship at **Hexafin Consultancy Private Limited**. The data in this repo is **synthetic** (generated by `src/generate_data.py`) so no company data is shared.

## Business problem

Sales and marketing effort was spread evenly across all customers and leads. The goal was to answer two questions:

1. Which customers are most valuable, and which are slipping away?
2. Which lead sources actually convert into revenue?

## Approach

**Customer segmentation**
- Built RFM features per customer: **Recency** (days since last order), **Frequency** (number of orders), **Monetary** (total spend).
- Scaled the features and clustered customers with **K-Means (k=3)**.
- Named each cluster in business terms: *Champions*, *Potential*, *At Risk*.

**Lead analytics**
- Calculated conversion rate and revenue per lead by **source** and **region**.
- Tracked the **monthly lead trend** to monitor performance over time.

## Key findings (on the sample data)

| Segment | Customers | Avg recency (days) | Avg orders | Revenue share |
|---|---|---|---|---|
| Champions (high value) | 106 | 34.6 | 17.5 | 76.9% |
| Potential (occasional) | 231 | 122.4 | 4.7 | 18.6% |
| At Risk (inactive) | 163 | 281.0 | 2.1 | 4.4% |

- About 21% of customers (Champions) generate about 77% of revenue, so they should be retained first.
- At Risk customers have been inactive for about 9 months on average, so they are a target for win-back campaigns.

| Lead source | Leads | Conversion rate | Revenue per lead |
|---|---|---|---|
| Referral | 144 | 28.5% | 667.0 |
| Trade Show | 140 | 24.3% | 619.8 |
| LinkedIn | 318 | 18.2% | 453.9 |
| Website | 374 | 16.6% | 407.0 |
| Email Campaign | 204 | 11.3% | 281.4 |
| Cold Call | 320 | 8.4% | 211.1 |

- Referrals convert about 3x better than cold calls, so shifting effort toward referrals and trade shows would raise conversion.

Charts are saved in `outputs/` (`segments.png`, `lead_conversion_by_source.png`).

## Project structure

```
customer-segmentation-lead-analytics/
├── main.py                  # runs the full pipeline
├── requirements.txt
├── src/
│   ├── generate_data.py     # creates synthetic transactions + leads
│   ├── segmentation.py      # RFM + K-Means
│   └── lead_analysis.py     # lead conversion analytics
├── data/                    # input CSVs (generated)
└── outputs/                 # result CSVs and charts
```

## How to run

```bash
git clone https://github.com/Mragank45/customer-segmentation-lead-analytics.git
cd customer-segmentation-lead-analytics
pip install -r requirements.txt
python main.py
```

To use your own data, replace `data/transactions.csv` (`customer_id, order_date, amount`) and `data/leads.csv` (`lead_id, source, region, created_date, converted, deal_value`) and run `segmentation.py` and `lead_analysis.py` directly.
